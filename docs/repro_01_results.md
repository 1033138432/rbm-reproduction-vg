# RoboBenchMart × π0.5 LoRA 项目最终报告

> 硬件：单卡 NVIDIA L40 (44.4 GB)，128 核，磁盘 197 GB
> 规模：**12 轮训练、约 120 GPU·小时、约 80 次评测、约 40 万训练步**

---

## 一、最终结论（一句话）

> **在 RoboBenchMart 的 pick-and-place 任务上，用离线示范 + LoRA 微调 π0.5，
> 无法跨越闭环执行差距。** 数据量 60→217 条、训练 3k→8k 步、裁剪 +
> RHC-10→RHC-1，全部无效。离线指标（loss 0.029、动作 MAE 0.05）与真值回放
> （3/3 成功）都正常，但闭环成功率恒为 0。

同时，本项目**定位并定量证明了评测链路上的一个关键契约问题**：初始机器人姿态，
它单独决定了 0% 与 60~85% 的差别。

---

## 二、全部基线实测（我们自己的评测壳子）

| 任务 | 条件 | 官方模型成功率 |
|---|---|---|
| pick_to_basket | 训练场景 + pose A（演示初始姿态）| **85%**（17/20）|
| pick_to_basket | 留出场景（Nivea，未见布局）+ pose A | **70%**（7/10）|
| pick_to_basket | 环境默认 reset（pose B）| **0/10** |
| pick_from_floor | 训练场景 + pose A | **60%**（6/10）|
| pick_from_floor | 训练场景 + pose B | **0/10** |
| pick_from_floor | 我们生成的新场景（pose B）| **0/10** |
| pick_from_floor | 随机 seed（pose B）| **10%**（1/10）|

**关键洞察**：同一个官方模型，在**同一批场景**上，仅把初始姿态从 pose A 换成
pose B，成功率就从 60% 掉到 0%。**初始姿态是比模型能力更强的变量。**

### v10 的意义

这是唯一一次成功的训练：从官方权重出发做 LoRA，在 pick_to_basket 上达到 45%
（9/20，95% CI 33–63%），而官方全参数基线在同协议下是 85%。

**但它不构成方法学贡献**——官方权重已经会这个任务，同分布再训只会退化
（在官方权重上直接评测是 85%，训完反而降到 45%）。

## 四、v12 的关键诊断：为什么 217 条数据 + 8k 步仍然是 0

| 检查项 | 结果 | 说明 |
|---|---|---|
| 训练 loss | 1.71 → **0.029**（−98%）| 拟合充分 |
| 离线动作 MAE | **0.05–0.13** | 预测很准 |
| 真值回放（生成数据）| **3/3 成功** | 数据有效 |
| 场景可复现性 | 重新生成后初始状态**逐位相同**（差异 0.000000）| 环境确定性 |
| 闭环（训练场景）| **0/10** | ← 关键异常 |
| 闭环 + RHC-1（每步重规划）| **0/10** | 不是开环累积误差 |
| 闭环 + clip-actions | **0/10** | 不是动作越界 |
| 动作越界率 | 官方 1.66%（全在夹爪维），我们的 8.92% | 裁剪无实质影响 |

**四条独立证据指向同一结论**：策略在闭环中一旦偏离示范状态就无法恢复，
而训练数据里**只有成功轨迹，没有任何"从偏离状态恢复"的样本**——这是行为克隆的
经典曝光偏差（covariate shift）。

## 六、方法论沉淀

### 6.1 四级诊断法（把"0% 成功率"拆到具体维度）

1. **离线预测**：用数据集真实观测问策略 → 验证数据/预处理/归一化管线
   （本项目 MAE 0.03–0.13，证明管线正确）
2. **真值回放**：把真值动作喂进评测环境 → 验证环境/动作语义/成功判定
   （官方数据 3/3 成功；自采数据曾 0/3，直接暴露数据无效）
3. **逐步 divergence**：策略轨迹与演示逐帧对齐，看**最大单维误差**而非平均值
   （平均值会被 12 个正常关节稀释）
4. **维度级对比**：逐维对比动作，定位唯一异常维度，回溯其训练分布

### 6.2 最重要的教训

> **训练前必须做"真值回放"验证数据有效性。**

我用它抓出了自己生成的第一批 80 条数据（0/3 失败），当时若不做这一步就白跑 3 轮训练。
这次也同样用它确认了 217 条新数据是有效的（3/3）。

### 6.3 初始姿态契约

```
同一模型、同一批场景、同一套代码：
  初始姿态 = 演示姿态(pose A) → 60~85%
  初始姿态 = 环境默认(pose B) → 0%
```

这个变量**从未被官方文档提及**，但它单独决定了成败。
